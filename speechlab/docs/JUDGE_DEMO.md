# SpeechLab judge demo

1. Submit an ideal speech rubric and a timestamped learner transcript.
2. Show the overall score plus separate pace, clarity and structure scores.
3. Click/inspect a flaw with its timestamp and exact evidence.
4. Show the coaching action generated for that flaw.
5. Explain that the same deterministic scoring contract can consume ASR timestamps and acoustic features in production.

The key judging property is reproducibility: identical transcript input produces identical rubric scores and flaw timestamps.
