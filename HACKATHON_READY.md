# Hackathon-ready build map

This repository keeps the two solution modules isolated.

## Track D — TutorMind AI
Location: `tutormind/`

Flow: course material → ingestion → grounded retrieval → cited tutor → assessment → persistent mastery → adaptive next question.

## Track C — SpeechLab
Location: `speechlab/`

Flow: ideal rubric + timestamped learner transcript → reproducible scoring → temporal flaws → actionable coaching.

## Final demo discipline

- Use one coherent course topic for TutorMind.
- Use one short ideal/learner speech pair for SpeechLab.
- Demonstrate evidence, not slides full of claims.
- Show a visible before/after learner state.
- Keep API keys server-side and disclose AI tooling as required by the event.
- Do not claim production video/audio or external-model capabilities unless they are actually enabled in the submitted deployment.
